# Foundations

A course for the Claude Certified Architect exams, built one lesson at a time.
Every lesson ends with something installed for real, not an example.

**Open it:** https://naelseddin-cpu.github.io/Training-/

## What is here

| | |
|---|---|
| `index.html` | the front page |
| `words.html` | twenty-seven words, starting from what a file is |
| `lesson-01.html` | Lesson 1 — Locks |
| `course/` | the plan, the scores, the picture prompts, the tools |

Open `index.html` in any browser. No server, nothing to install.

## Two versions of the same thing

The pages here are a plain reading copy and remember nothing.
The live version keeps your place across devices and answers questions inside
the page.

`course/spec.md` explains how the whole course works, so it survives being
picked up months later by someone new.
